Overview (نظرة عامة)

This is a self-hosted Telegram multi-account manager: sessions are encrypted in local SQLite and can be operated through the web or a bot. It is suited for bulk imports, health checks, device cleanup, broadcasts, lead collection, and ZIP pack tools. (هذا مدير حسابات تيليجرام متعدد مستضاف ذاتيًا: تُشفّر الجلسات في SQLite المحلي ويمكن تشغيله عبر الويب أو روبوت. وهو مناسب للاستيراد الجماعي وفحص الحالة وتنظيف الأجهزة والإرسال الجماعي وجمع العملاء وأدوات حزم ZIP.)

Top right, Access Token: enter TAM_WEB_TOKEN here when configured; leave it empty for local tokenless mode. The top bar also has Health Check, Hot Reload, and Error Log. (في أعلى اليمين، رمز الوصول: أدخل TAM_WEB_TOKEN عند ضبطه؛ اتركه فارغًا للوضع المحلي بلا رمز. ويحتوي الشريط العلوي أيضًا على فحص الحالة وإعادة التحميل السريع وسجل الأخطاء.)

Quick Start (بدء سريع)

  • Double-click start.bat (Windows) or run ./start.sh, then choose local/server and web/bot/both. (انقر مرتين على start.bat في Windows أو شغّل ./start.sh ثم اختر محلي/خادم وويب/روبوت/كلاهما.)
  • The Windows “cannot verify publisher” message is for an unsigned script; click Run, or first run unblock.bat / choose “Unblock” in Properties. (رسالة Windows «تعذر التحقق من الناشر» تخص برنامجًا نصيًا غير موقّع؛ انقر تشغيل، أو شغّل unblock.bat أولًا / اختر «إلغاء الحظر» من الخصائص.)
  • Open the displayed address in your browser (the local default is http://127.0.0.1:8848). (افتح العنوان الظاهر في المتصفح؛ الافتراضي المحلي هو http://127.0.0.1:8848.)
  • Click “Health Check” first, then import accounts. (انقر «فحص الحالة» أولًا ثم استورد الحسابات.)

Account Management (إدارة الحسابات)

  • Add Account: alias, phone number, proxy, tags, code-source link, and more. (إضافة حساب: الاسم المستعار ورقم الهاتف والوكيل والوسوم ورابط مصدر الرمز وغير ذلك.)
  • Select + bulk bar: health check, auto login, send messages, warm up, proxy check, OKPay balance, kick devices, tag, export, regenerate session, delete, and more. (التحديد + شريط الإجراءات الجماعية: فحص الحالة وتسجيل الدخول التلقائي وإرسال الرسائل وتهيئة الحساب وفحص الوكيل ورصيد OKPay وطرد الأجهزة ووضع الوسوم والتصدير وإعادة إنشاء الجلسة والحذف وغير ذلك.)
  • Open a row: profile, health check, restriction check, devices/sessions, login, clear devices, export, regenerate, 2FA status/reset, logout, and delete. (افتح صفًا: الملف الشخصي وفحص الحالة وفحص القيود والأجهزة/الجلسات وتسجيل الدخول ومسح الأجهزة والتصدير وإعادة الإنشاء وحالة/إعادة ضبط التحقق بخطوتين وتسجيل الخروج والحذف.)
  • Status: active is normal, restricted is limited, banned is blocked, and unauthorized is not logged in/invalid. (الحالة: active طبيعي، وrestricted مقيّد، وbanned محظور، وunauthorized غير مسجل الدخول/غير صالح.)
  • Bulk operations show real progress (completed/success/failed/current account); see the Settings Panel for concurrency and timeouts. (تُظهر العمليات الجماعية تقدمًا حقيقيًا (المكتمل/الناجح/الفاشل/الحساب الحالي)؛ راجع لوحة الإعدادات للتوازي والمهلات.)

Export (تصدير)

  • StringSession / .session / pack zip (session+json). (StringSession / .session / حزمة zip (session+json).)
  • tdata: real Desktop directory structure (the server must have opentele installed). If missing, the dialog offers one-click installation. (tdata: بنية مجلد Desktop حقيقية (يجب تثبيت opentele على الخادم). عند غيابه توفر النافذة تثبيتًا بنقرة واحدة.)

Export only converts sessions already in the library; it does not create new authorizations. Credentials grant login access—never disclose them. (يحوّل التصدير الجلسات الموجودة في المكتبة فقط ولا ينشئ تفويضات جديدة. بيانات الاعتماد تعادل صلاحية الدخول—لا تفصح عنها.)

Regenerate Session (web anti-recovery) (إعادة إنشاء الجلسة (منع الاسترداد عبر الويب))

Like the bot’s “anti-recovery”: log in again with a new device fingerprint, attempt to revoke the old session, replace the library session, and reset the takeover time. (مثل «منع الاسترداد» في الروبوت: تسجيل الدخول ببصمة جهاز جديدة ومحاولة إلغاء الجلسة القديمة واستبدال جلسة المكتبة وإعادة ضبط وقت الاستلام.)

  • A phone number is required; if 2FA is enabled, enter its password (a password saved in this tool is used automatically; bulk operations can use one shared password). (رقم الهاتف مطلوب؛ إذا كان التحقق بخطوتين مفعّلًا فأدخل كلمة مروره (تُستخدم تلقائيًا كلمة محفوظة في هذه الأداة؛ ويمكن للعمليات الجماعية استخدام كلمة موحدة).)
  • Export after success; tdata is not generated automatically during regeneration. (صدّر بعد النجاح؛ لا يتم إنشاء tdata تلقائيًا أثناء إعادة الإنشاء.)
  • Rate limiting: several regenerations or incorrect 2FA attempts in a short time may make Telegram return PhonePasswordFlood (too many logins). Wait several hours to 24 hours; do not repeatedly click regenerate. (تحديد المعدل: قد تعيد تيليجرام PhonePasswordFlood بعد عمليات إعادة إنشاء أو محاولات 2FA خاطئة كثيرة خلال وقت قصير (عمليات دخول كثيرة). انتظر من عدة ساعات إلى 24 ساعة ولا تنقر إعادة الإنشاء مرارًا.)

QR Login (تسجيل الدخول عبر QR)

In account details, click “QR Login”: the web page shows a QR code; scan it with the official Telegram app already signed in on your phone to authorize, and the session is encrypted into the library. No SMS code is needed; if a cloud password is enabled, enter it once after scanning. (في تفاصيل الحساب انقر «تسجيل الدخول عبر QR»: تعرض الصفحة رمز QR؛ امسحه بتطبيق تيليجرام الرسمي المسجل على هاتفك للتفويض، وتُخزّن الجلسة مشفرة في المكتبة. لا يلزم رمز SMS؛ وإذا كانت كلمة المرور السحابية مفعّلة فأدخلها مرة بعد المسح.)

  • Useful for accounts without a code-source link or for quickly taking over an account already on a phone. (مفيد للحسابات بلا رابط مصدر رمز أو للاستلام السريع لحساب موجود على هاتف.)
  • QR codes expire after about 30 seconds and the page will prompt a refresh; do not start multiple requests to avoid rate limits. (تنتهي رموز QR بعد نحو 30 ثانية وستطلب الصفحة تحديثها؛ لا تبدأ طلبات متعددة لتجنب تحديد المعدل.)

Auto Login (تسجيل الدخول تلقائيًا)

This depends on the account’s code-source link. Without one, log in manually, use QR Login, or import session/tdata directly. (يعتمد ذلك على رابط مصدر الرمز في الحساب. عند غيابه سجّل الدخول يدويًا أو عبر QR أو استورد session/tdata مباشرة.)

Clear Devices (مسح الأجهزة) / OKPay

  • Automatic device cleanup starts from the “local takeover time”; details let you set participation, interval, and looping. (يبدأ تنظيف الأجهزة التلقائي من «وقت الاستلام المحلي»؛ ويمكن من التفاصيل ضبط المشاركة والفترة والتكرار.)
  • Kicking other devices verifies that cleanup succeeded; failures are retried after the configured interval. (يتحقق طرد الأجهزة الأخرى من نجاح التنظيف؛ وتُعاد محاولة الفشل بعد الفترة المضبوطة.)
  • OKPay OKPay balance: query signed-in accounts (requires the corresponding business configuration). (رصيد OKPay: استعلم عن الحسابات المسجل دخولها (يتطلب إعداد الخدمة المعني).)

Tasks & Leads (المهام والعملاء المحتملون)

Broadcasts and recent-speaker collection run through the Task Center; you can view progress and stop them. Filter the Lead Library before using it for broadcasts. (تعمل عمليات الإرسال الجماعي وجمع أحدث المتحدثين عبر مركز المهام؛ ويمكنك عرض التقدم وإيقافها. صفِّ مكتبة العملاء قبل استخدامها للإرسال الجماعي.)

2FA & Reset (التحقق بخطوتين وإعادة الضبط)

  • Change 2FA: available in the Toolbox / Details; you may save the new password encrypted in the library. (تغيير التحقق بخطوتين: متاح في صندوق الأدوات/التفاصيل؛ ويمكنك حفظ كلمة المرور الجديدة مشفرة في المكتبة.)
  • 2FA Status: whether 2FA is enabled, whether a recovery email is linked, and whether a reset wait is active. (حالة التحقق بخطوتين: هل هو مفعّل، وهل يوجد بريد استرداد مرتبط، وهل توجد فترة انتظار لإعادة الضبط.)
  • Start 2FA Reset: follows the official flow and usually waits about 7 days; the cloud password expires afterward. With a recovery email, the previous owner may still recover access by email—check the status first. (بدء إعادة ضبط 2FA: يتبع الإجراء الرسمي وعادة ينتظر نحو 7 أيام؛ وتنتهي كلمة المرور السحابية بعد ذلك. مع بريد استرداد قد يتمكن المالك السابق من الاسترداد عبر البريد—تحقق من الحالة أولًا.)
  • Cancel 2FA Reset: cancel an active wait. (إلغاء إعادة ضبط 2FA: إلغاء فترة انتظار نشطة.)
  • Supports single-account and multi-select bulk operations. (يدعم الحساب الواحد والعمليات الجماعية متعددة التحديد.)

Toolbox (صندوق الأدوات)

Run in bulk on selected library accounts: activity check, restriction check, privacy, filtering, 2FA changes, 2FA status/reset, contact/session cleanup, anti-recovery cleanup, block/unblock users, public-group search, joining groups, member lists, reading group messages, kicking devices, and more. Dangerous items require confirmation. (نفّذ جماعيًا على حسابات المكتبة المحددة: فحص النشاط والقيود والخصوصية والتصفية وتغيير 2FA وحالة/إعادة ضبط 2FA وتنظيف جهات الاتصال/الجلسات والتنظيف المضاد للاسترداد وحظر/إلغاء حظر المستخدمين والبحث عن المجموعات العامة والانضمام إليها وقوائم الأعضاء وقراءة رسائل المجموعة وطرد الأجهزة وغير ذلك. تتطلب العناصر الخطرة تأكيدًا.)

ZIP Tools (does not touch library accounts) (أدوات ZIP (لا تمس حسابات المكتبة))

  • Split / merge / classify by registration time / convert to API: aligned with the bot’s pack capabilities. (التقسيم / الدمج / التصنيف حسب وقت التسجيل / التحويل إلى API: متوافق مع إمكانات الحزم في الروبوت.)
  • Format conversion: Session→Tdata (requires opentele) or Tdata→Session (built-in parser). (تحويل الصيغ: من Session إلى Tdata (يتطلب opentele) أو من Tdata إلى Session (محلل مدمج).)
  • Passkey: upload a session pack, initialize Passkey registration, and download a credential zip (creation direction). (Passkey: ارفع حزمة session وابدأ تسجيل Passkey ونزّل zip لبيانات الاعتماد (اتجاه الإنشاء).)

Download results, then click “Delete When Done”. Pack tools are ported from GAFBot (MIT); see NOTICE.GAFBot. (نزّل النتائج ثم انقر «الحذف بعد الاستخدام». أدوات الحزم منقولة من GAFBot (MIT)؛ راجع NOTICE.GAFBot.)

Hot Reload & Error Logs (إعادة التحميل السريع وسجلات الأخطاء)

  • Hot Reload: actually restarts the backend process (os.execv); it is not a page refresh. Active tasks are interrupted; the frontend detects recovery after about 1–3 seconds. (إعادة التحميل السريع: تعيد تشغيل عملية الخادم فعليًا (os.execv) وليست تحديثًا للصفحة. تُقاطع المهام النشطة؛ ويكتشف الواجهة التعافي بعد نحو 1–3 ثوانٍ.)
  • Error Log: records uncaught server exceptions, HTTP 5xx errors, and frontend script errors. View the list, export JSON for reporting, or clear it. (سجل الأخطاء: يسجل استثناءات الخادم غير الملتقطة وأخطاء HTTP 5xx وأخطاء نصوص الواجهة. اعرض القائمة أو صدّر JSON للإبلاغ أو امسحها.)
  • File copy: errors.log in the data directory (it can retain evidence even when the DB fails). (نسخة ملف: errors.log في مجلد البيانات (قد تحتفظ بالأثر حتى عند فشل قاعدة البيانات).)

Settings & Layout (الإعدادات والتخطيط)

  • TAM_BATCH_CONCURRENCY: bulk concurrency (1–32). (TAM_BATCH_CONCURRENCY: التوازي الجماعي (1–32).)
  • TAM_REGEN_CONCURRENCY: regeneration concurrency (1–8). (TAM_REGEN_CONCURRENCY: توازي إعادة الإنشاء (1–8).)
  • TAM_UI_OP_TIMEOUT: per-account timeout in seconds; timeouts are skipped to avoid hangs. (TAM_UI_OP_TIMEOUT: مهلة الحساب الواحد بالثواني؛ تُتخطى المهلة لتجنب التجمّد.)
  • Edit Layout: drag the board; layout JSON can be exported/imported. (تحرير التخطيط: اسحب اللوحة؛ يمكن تصدير/استيراد JSON للتخطيط.)

Web & Bot (الويب والروبوت)

With TAM_FRONTEND=both, one process runs the web and bot, sharing .env and the data directory, but the account library is used only by the web/API. The bot handles temporary pack ZIPs by default and does not automatically write to the managed table. Pack features such as Passkey/format conversion are available in both; device kicking, login, and the Task Center are governed by the web UI. (عند استخدام TAM_FRONTEND=both يشغّل نفس process الويب والروبوت ويشاركان .env ومجلد البيانات، لكن مكتبة الحسابات يستخدمها الويب/API فقط. يعالج الروبوت حزم ZIP المؤقتة افتراضيًا ولا يكتب تلقائيًا في جدول الإدارة. تتوفر ميزات الحزم مثل Passkey وتحويل الصيغ في كليهما؛ ويُعتمد الويب لطرد الأجهزة وتسجيل الدخول ومركز المهام.)

AI Assistant (مساعد الذكاء الاصطناعي)

Click ✦ at the bottom right or “AI Assistant” in the top bar to open the panel. Configure an upstream (OpenAI-compatible / Claude / Gemini / Azure) and key, check Enable AI Assistant, and click “Save Configuration” for it to take effect; disabling it also requires saving. Choose permissions with a preset (read-only/safe/standard/full) via “Apply Preset to Selected”, or select tools individually. New tools added after an upgrade receive default switches from the current preset. The standard preset excludes account deletion/logout; only the full preset includes them. Login and session import/export are never exposed to AI. (انقر ✦ أسفل اليمين أو «مساعد الذكاء الاصطناعي» في الشريط العلوي لفتح اللوحة. اضبط upstream (متوافق مع OpenAI / Claude / Gemini / Azure) والمفتاح، وحدد تفعيل مساعد الذكاء الاصطناعي ثم انقر «حفظ الإعدادات» ليصبح فعالًا؛ ويتطلب تعطيله الحفظ أيضًا. اختر الصلاحيات بإعداد مسبق (للقراءة فقط/آمن/قياسي/كامل) عبر «تطبيق الإعداد المسبق على المحدد»، أو حدد الأدوات واحدةً واحدة. تحصل الأدوات الجديدة بعد التحديث على مفاتيح افتراضية من الإعداد الحالي. لا يتضمن الإعداد القياسي حذف الحساب/تسجيل الخروج؛ يتضمنها الكامل فقط. لا يُفتح تسجيل الدخول واستيراد/تصدير session للذكاء الاصطناعي.)

Security Notes (ملاحظات الأمان)

  • The master key encrypts sessions; back up .env / the master key because losing it prevents decrypting old sessions. (يشفر المفتاح الرئيسي الجلسات؛ انسخ .env / المفتاح الرئيسي احتياطيًا لأن فقدانه يمنع فك تشفير الجلسات القديمة.)
  • Exports, regenerated sessions, and API conversion artifacts are equivalent to login credentials; do not share them publicly. (التصديرات والجلسات المعاد إنشاؤها ونواتج التحويل إلى API تعادل بيانات الدخول؛ لا تنشرها.)
  • Use a strong token on servers and HTTPS is recommended; the default is local 127.0.0.1. (استخدم رمزًا قويًا على الخوادم ويُنصح بـ HTTPS؛ الافتراضي هو 127.0.0.1 المحلي.)
  • Read-only/Agent tokens cannot perform write operations such as import or login; hot reload is disabled in read-only mode. (لا تستطيع رموز القراءة فقط/Agent تنفيذ عمليات الكتابة مثل الاستيراد أو تسجيل الدخول؛ وتعطّل إعادة التحميل السريع في وضع القراءة فقط.)
